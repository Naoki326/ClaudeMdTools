# lanbook 1.11.0

本版包含新增功能，版本从 1.10.1 升至 1.11.0。配置位置与现有 HTTP 接口保持兼容。

## 新增

- 知识库和课程设置都支持 **HTML 内嵌文件夹选择器**：浏览子目录、返回上级、主目录、常用位置和输入绝对路径前往，不调用 Windows 原生选择窗口、不上传文件。
- 选择的是运行 lanbook 的电脑上的目录，手机 / 平板也可使用。选择后只回填路径，仍需点击“添加”“保存”。
- 目录按当前层分页读取；不新增后台 watcher、目录缓存或轮询，支持取消请求及忽略迟到响应。

## 修复与资源保护

- 课程列表与 HTML/CSS/JS 静态文件共用异步索引，展开、折叠和选中课程不再反复扫描全部根目录。
- 排除 `worktree-archive` 归档副本，保留 `.scratch` 正本和合法同名课程，不删除原文件。
- 设置根目录列表可滚动，限制弹窗尺寸，适配窄屏及矮屏，避免按钮被挤出屏幕。
- 知识库串行异步扫描，课程刷新 single-flight 合并；监听和标题缓存设预算，删除文件与移出根目录时回收缓存。
- 修复 V8 短标题子串可能保留整篇文档正文的问题。
- 修复直接配置磁盘根目录（如 `D:/`、`/`）时子目录监听被排除的问题，并正确归并磁盘根下的重复子根。
- 等旧 watcher 关闭后再创建新监听；关闭失败不创建重叠 watcher，退出时撤销课程定时器及待执行任务。

## 更新行为与限制

- 课程新增 / 删除整个目录默认每 30 秒发现；慢扫描自动延长间隔，最高 5 分钟。已有课程编辑仍由局部 watcher 处理。
- 知识库超出实时监听预算时，快照完成满 60 秒后的下一次访问才按需重建；空闲不扫描，不保证超限部分实时推送。
- 文件夹选择器只返回目录名称，不返回普通文件或内容。它可以浏览尚未配置为根目录的本地位置；**lanbook 仍无鉴权，只适用于可信内网**。Windows UNC / 设备路径不用于浏览，其他本地磁盘可手动输入盘符前往。
- 预算不是进程总内存硬上限；完整知识库元数据仍随文档数量增长。短时资源采样不能证明无限运行时间内无泄漏。

详细策略见 [常驻资源与刷新策略](../runtime-resources.md)。

## 发布边界

- 同步 `package.json`、`package-lock.json` 与 README 版本标识；依赖版本不变。
- 本版不纳入工作区原有的 Windows 自启单实例修订，避免将独立未提交工作混入发布。
- 发布准备不等于已经发布到 npm：包验证、提交和推送完成后，再由发布者执行 `npm publish`。
