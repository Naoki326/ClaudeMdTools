# 默认监听 0.0.0.0，不收敛到 localhost

工具的主场景就是手机 / 平板连同一 Wi-Fi 访问；vite 等 dev server 默认 localhost 是因为它们不面向「给别人访问」，我们正相反。公开发布带来的风险（局域网内任意设备可读写所配置目录）通过启动横幅 + README 安全章节明示，而不是改变默认值。

## Considered Options

- 0.0.0.0 + 启动警告（选定：主场景零损耗）
- 默认 127.0.0.1，`--lan` 显式开启（同 dev server 惯例，但新手「手机打不开」会困惑）
- 0.0.0.0 + 简单 token 鉴权（多一层实现与交互，v1 不做）
