# 常驻资源与刷新策略

lanbook 应在空闲时保持低开销，而不是随访问次数、文件改名或配置保存持续增加监听和缓存。以下是代码层面的约束，不是对任意大小目录、外部请求流量或无限运行时间的内存保证。

## 课程

实现入口：`lib/courses.js`；`server.js` 只接 HTTP / WebSocket。

- 首次启动异步建立索引；并发冷请求共享一趟扫描。课程列表、HTML、CSS、JS 的暖请求都不扫描根目录。
- 展开、折叠和选中课程只重绘前端缓存；通知、重连与保存配置使列表过期。
- 原有课程目录内的 HTML、MISSION、CSS、JS 编辑经去抖合并更新，不重新发现全部根目录。
- 新增或移除整个课程目录通过定期发现收录。默认扫描完成后至少等待 30 秒；按扫描耗时自适应拉长间隔，最高 5 分钟。只保留一个刷新任务，不叠加扫描或待执行队列。
- 无变化的周期不广播、不刷新 iframe、不逐次写日志。目录发现使用异步流式遍历，不递归监听整个课程根目录。
- 每次索引替换旧快照和标题缓存，删除的课程、文件与根目录不会永远留在缓存中；不缓存课程正文或静态资源。
- 只监听发现的课程工作区；更新监听集合前先等待旧 watcher 关闭。关闭时撤销定时器、停止在飞任务，不能重新启动 watcher。

默认预算：

| 项目 | 上限 |
| --- | ---: |
| 配置根目录 | 256 |
| 单趟遍历目录 | 50,000 |
| 工作区 | 512 |
| 索引文件（含 MISSION 探测） | 10,000 |
| 单文件标题读取 | 前 16 KiB |
| 标题长度 | 512 字符 |
| 实时监听目录 / 文件 | 2,048 / 10,000 |
| 发现 / 课程内容递归深度 | 8 层 |
| 单趟扫描时间检查 | 30 秒 |

监听预算超限时，后续发现会重新核对监听集合，回收在监听落地前已消失、不会产生 unlink 事件的路径预留；旧监听关闭失败则不再创建重叠 watcher。

时间检查是协作式的：在文件系统调用之间检查，不能中断操作系统内部正在等待的磁盘或网络 I/O。

**超限行为**：扫描超限会报错并保留上次成功索引，不提交半份列表；首次扫描没有旧索引时，课程接口返回错误。监听超限只告警一次，未被监听部分的课程列表变化仍由定期发现收录，CSS/JS 的变化可能需要手动刷新。应缩小根目录到实际课程所在的父目录，而不是无限提高预算。

## 知识库

实现入口：`lib/knowledge.js`。

- 目录树扫描改为串行异步遍历，避免目录扇出通过递归 `Promise.all` 放大文件读取并发。
- 标题缓存最多 10,000 条，成功扫描后清理已删除文件和移出根目录的条目；超过 512 字符的标题原样响应但不缓存。标题显式复制，避免 V8 子串间接留住整篇文档正文。
- 实时监听最多接纳 2,048 个目录和 10,000 篇文档，不使用 polling 或 awaitWriteFinish 轮询。不跟随链接，配置反复保存时先关闭旧监听，再合并到最新配置。
- 超监听预算仅告警一次。此时快照完成满 60 秒后的**下一次访问**才触发 single-flight 异步重建，并重新核对监听集合，回收未落地的预算预留；无访问不扫描，不额外创建定时器。更新延迟包含等待访问及扫描耗时，并非保证 60 秒内主动推送。
- 正常未超限仍由 watcher 去抖失效，不因快照年龄而反复扫描。存在性探测跨过一次已完成重建时，复用新快照，不再重复扫描。
- 完整树元数据仍随收录文档数量增长；本次不设置进程总内存硬上限，也不截断知识库文档内容。

## HTML 文件夹选择器

- 只在打开、导航或加载下一页时请求当前层目录，不递归扫描，也不启动 watcher、定时器或常驻目录缓存。
- 后端并发浏览有限额，相同请求合并；子目录列表分页并设扫描预算，超限要求输入更具体的路径，不无限堆积任务。
- 前端取消 / 关闭 / 切换路径会中止旧请求，忽略迟到响应，关闭后释放当前选择器状态；只有一个活动选择弹窗。
- 选择只回填输入框，不自动添加根目录、更改配置或上传文件。

## 归档与副本

扫描、预览、监听均排除 `worktree-archive`，但保留 `.scratch`，因此 `.scratch/teach` 正本仍然收录。文件不移动、不删除，不按名称或内容哈希去重，正常的同名课程可以并存。

## 验证边界

- `test/course-service.test.js` 验证缓存命中、并发合并、真实 watcher 更新、周期发现、根恢复、旧 ID 保持、监听预算及关闭回收。
- `test/course-cache.test.js` 验证真实 HTTP 列表与预览不收录归档副本。
- `test/course-client.test.js` 验证真实前端函数的本地重绘和网络刷新语义。
- `test/knowledge-resources.test.js` 验证知识库监听与标题缓存预算、失效竞态、按需降级和关闭回收；`test/fixtures/title-retention.cjs` 通过独立 GC 子进程验证短标题不会保留整篇正文。
- 数分钟资源采样只能验证短时基线；长期泄漏还需跨天观察工作集、私有提交量、句柄和 CPU 增量，不能只比较进程刚启动与运行数日后的内存。
